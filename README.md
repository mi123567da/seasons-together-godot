# 四季同行：港湾远征

这是一个 Godot 4.7 单人玩法原型。首次进入时选择外观与称呼，之后从可探索的港湾出发。玩家可在港湾解锁、装备武器并更换外观；每次远征依次挑战四个季节房间，达到击杀配额、击败首领并领取奖励后打开下一扇门。完成最终房间后返回结算，再回到港湾。

## 操作

- 港湾：WASD、方向键或手柄左摇杆移动；靠近武器架、强化台或远征门后按 E / 手柄 A 互动。
- 战斗：WASD、方向键或左摇杆移动；鼠标左键普攻（J 或手柄 A 也可攻击）；空格 / Shift / 手柄 B 闪避；Q / E / R 或手柄 X / Y / RB 施放武器技能；F2 / 手柄返回键打开设置。
- 结算页：按回车 / 手柄 A 返回港湾。

## 武器与外观

主角是同一个战斗角色。性别只影响头像外观和称呼，不影响战斗数值或技能。武器对应既有战斗配置：长弓 → Shade、长剑 → Blade、法杖 → Bloom、灵契法器 → Gale。武器等级会略微提升伤害。港湾印记的获取量、武器解锁顺序和花费是当前试玩用的临时数值，配置见 `hub/weapon_costs.json`；结算按普通敌人 +1、首领 +5 发放，与旧档案中的金币和符文分开。

港湾与战斗中的角色头像是可替换占位图，使用已有的获准美术素材副本。作品仅借鉴《Hades II》的房间推进节奏；本原型使用自有名称、代码和界面，不包含该系列的美术素材或其他受版权保护的游戏内容。

## 主角位图动画槽

战斗主角已接入 `BitmapAnimationCatalog`。美术交付位图时放入 `assets/animation_slots/{female|male}/{bow|sword|staff|spirit_focus}/{idle|run|basic|q|e|r|dash|hurt}/{N|NE|E|SE|S}_00.png` 等槽位；图片为 256×256 透明 PNG，以底部中心 (0.5, 1.0) 对齐。西、左上、左下分别镜像复用东、右上、右下序列，不对图片做 180° 旋转。帧数及时序由 `scripts/bitmap_animation_catalog.gd` 契约定义：idle 4 帧循环、run 5 帧循环、普攻与 Q/E/R 各 5 帧单次播放；dash/hurt 各预留 5 帧。单次动作结束后按角色速度切回 run 或 idle；动作优先级为 hurt、dash、Q/E/R、普攻。缺图或一组方向帧不完整时整段使用现有头像，不影响伤害、技能或游玩。

美术负责人请先看 [美术修改清单](美术修改清单.md)：它区分了可直接按路径替换的主角/地图素材，以及仍需程序员配合接入的怪物、港湾道具、技能特效和界面图标。

## 存档与联机

已有成长存档保持原样。港湾性别、武器解锁/等级与港湾印记单独保存在 `user://hub_profile.json`。联机尚未实现；未来迁移的权威边界记录在 [NETWORKING-NOTES.md](NETWORKING-NOTES.md)。

## 启动与验证

使用 Godot 4.7.2 或更新版本打开 `project.godot` 并按 F5。本机交付目录另有中文版 Debug 试玩版 `build/四季同行-中文版-动作槽接入版-v2.exe`；GitHub 源码仓库不包含 `build/`，克隆后请用 Godot 编辑器启动。窗口可调整大小，游戏画面保持 16:9。项目内附 Noto Sans SC 字体和 SIL Open Font License 1.1，确保不同电脑上的中文界面可显示；许可文件位于 `assets/fonts/OFL-NotoSansSC.txt`。

此目录不附普通 Release 版：当前 4.7.2 Release 导出仍有启动崩溃问题，请使用编辑器或 Debug 试玩版。`四季同行-中文版-动作槽接入版-v2.exe` 已在 Windows GUI 实际启动，显示中文标题、春季第 1 房与现有静态主角头像；目前没有动画图片，故本轮未验收帧动画显示。集成 smoke 覆盖空槽回退、动作帧时序、8方向镜像、普攻/Q/E/R 状态与回 idle/run，以及四房配额、首领、奖励、开门、结算与返回港湾；设置、奖励、武器、档案及 BitmapAnimationCatalog 也各有通过的独立 headless smoke。这些自动化验证不能替代完整的实时通关测试。旧版 v3b 的实时战斗曾推进至 4/6 击杀、生命值 36/120 后倒下，不代表本次新版战斗结果。
